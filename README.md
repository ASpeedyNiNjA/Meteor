METEOR

Meteor is an innovative take on the FPS (First-Person-Shooter) videogame genre.
The concept being it is a dual-reticule shooter meant to be played on multiple monitors, ultra-wide monitors, or eventually a VR headset.
It's a shooting gallery arcade game akin to something like Time Crisis or an arcade game where you play with a physical gun for reference, also partly inspired by the classic arcade game Asteroid.

The player holds a mouse in each hand, one for each reticule.
The game will start being developed with two monitors in mind. One monitor per reticule. The game takes place in space meaing it uses the full viewing area in all directions.

The goal is to get a MVP (Minimum Viable Product) online, the MVP freely available while in the development phase.
